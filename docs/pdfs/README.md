# `docs/pdfs/` — generated PDF artifacts

This directory holds PDF builds of selected markdown documents. PDFs are generated by the scripts under [`../../scripts/`](../../scripts/):

| Script | Source | Output PDF |
|---|---|---|
| [`generate_handoff_pdf.py`](../../scripts/generate_handoff_pdf.py) | [`TECHNICAL_HANDOFF.md`](../../TECHNICAL_HANDOFF.md) | `TECHNICAL_HANDOFF.pdf` |
| [`generate_business_handoff_pdf.py`](../../scripts/generate_business_handoff_pdf.py) | [`BUSINESS_HANDOFF.md`](../../BUSINESS_HANDOFF.md) | `BUSINESS_HANDOFF.pdf` |
| [`generate_client_pdf.py`](../../scripts/generate_client_pdf.py) | [`METHODOLOGY_CLIENT.md`](../../METHODOLOGY_CLIENT.md) | `UFC_Elo_Methodology_Client.pdf` |

## Regenerating a PDF

From the repo root:

```bash
python3 scripts/generate_handoff_pdf.py            # Technical handoff
python3 scripts/generate_business_handoff_pdf.py   # Business handoff
python3 scripts/generate_client_pdf.py             # Methodology (client-facing)
```

The handoff generators use Pandoc → HTML → Chrome headless (no problematic Python deps). The client methodology generator uses `markdown` + `xhtml2pdf`.

## Source of truth

These PDFs are derived artifacts. **The markdown sources are canonical.** If the PDF and the markdown ever disagree, the markdown wins — regenerate the PDF.
